# Complete Student Management App
Flutter offline-first school app.

Included:
- Student registration/profile
- Father/guardian, B-Form, roll no, class, section, phone, address
- Search/filter students
- Monthly test schedule
- Marks entry
- Automatic total, percentage and grade
- Attendance records
- Progress dashboard
- Local SQLite database
- CSV export-ready data layer

Build:
1. Install Flutter SDK + Android Studio.
2. Open this folder.
3. Run `flutter create .`
4. Run `flutter pub get`
5. Run `flutter build apk --release`
APK: build/app/outputs/flutter-apk/app-release.apk
